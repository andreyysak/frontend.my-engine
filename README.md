# My Engine

My Engine is a web app for keeping track of your vehicles. Add cars of different types together with their specs, follow maintenance schedules and get reminders, and log fuel records and trips.

The UI follows the Telegram design system and its dark blue color palette. The project is at an early stage: it currently focuses on layout and mock data, and Firebase is planned as the backend.

## Requirements

- Node.js v24.14.0
- npm

## Getting started

Clone the repository:

```bash
git clone git@github.com:andreyysak/frontend.my-engine.git
cd frontend.my-engine
```

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```
